### Unused / Duplicate Dependency Analysis
- **`react-router-dom` (`^7.18.5`)**: Present in `package.json`, but `YoApp.tsx` and `App.tsx` use state-based tab switching (`const [tab, setTab] = useState<TabId>('chats')`) and modal overlays instead of URL routing. This package is currently dead weight in the production bundle.
- **Orphan Folders**: There are two auxiliary folders present in the repository root: `glasswave-motion-studio` and `glasswave-motion-studio (1)`. These appear to be imported design-exploration or template repositories containing duplicate UI kits. They are not referenced by `src/` or the build configuration.
